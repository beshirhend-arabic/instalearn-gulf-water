InstaLearn | نسخة التفاعل المشترك — اللغة العربية — الصف الثامن

المحتويات:
index.html  صفحة المنصة الأصلية بعد إضافة المزامنة
netlify/functions/events.mjs  وظيفة الخادم لحفظ التعليقات والإجابات والنقاط
package.json  الاعتماد البرمجي Netlify Blobs
netlify.toml  إعدادات النشر

مهم: لا يكفي فتح index.html أو رفعه منفردًا، ولا يكفي سحب الملف وحده إلى Netlify Drop.
يجب نشر المشروع كله عن طريق مستودع GitHub متصل بموقع Netlify (أو Netlify CLI مع --build).

خطوات GitHub + Netlify:
1. أنشئ مستودع GitHub جديدًا، وارفع محتويات هذا المجلد مع الحفاظ على مسار netlify/functions/events.mjs.
2. من Netlify: Add new project > Import an existing project > GitHub > اختر المستودع.
3. اترك Build command فارغًا، وPublish directory نقطة واحدة (.)، وFunctions directory netlify/functions.
4. انشر الموقع. تأكد من ظهور رسالة «🟢 متصل» أعلى الصفحة.
5. افتح الموقع من جهازين مختلفين. اكتب تعليقًا، وانتظر 4 ثوانٍ، ثم تأكد من ظهوره على الجهاز الثاني.
6. إذا رغبت في الاحتفاظ بالرابط القديم، اربط المستودع بموقع Netlify الحالي بدلًا من إنشاء موقع جديد.

تنبيهات:
- جميع الفرق تشاهد التعليقات والإجابات والنقاط نفسها. التحديث يتم تقريبًا كل 4 ثوانٍ وليس بثًا فوريًا لحظيًا.
- يجب عدم نشر أسماء الطلاب الشخصية أو بياناتهم الحساسة.
- النسخة لا تتضمن حسابات مستخدمين أو تسجيل دخول؛ يستطيع من يملك الرابط اختيار اسم أي فريق.
- زر المكافأة العشوائية معطل لمنع تعديل النقاط دون إشراف.
- النقاط الابتدائية والتعليقات القديمة الظاهرة في التصميم هي أمثلة تجريبية من الملف الأصلي.
- تصدير CSV لا يعني إدخال الدرجات تلقائيًا إلى PowerSchool.
- لم يتم اختبار النشر على حساب Netlify الخاص بك؛ يلزم اختبار جهازين بعد النشر.
